# Cryptography Toolkit

A simple Bash-based cryptography toolkit built with **Bash and OpenSSL**. It provides an interactive menu for performing common cryptographic and file operations.

## Features

- Symmetric encryption and decryption using AES-256-CBC
- Asymmetric encryption and decryption using RSA keys
- SHA-256 and SHA-512 file hashing
- Digital signature generation and verification
- RSA private/public key generation
- Create, view, rename, and delete files
- View hidden files
- Interactive menu using a `while` loop
- Basic error handling and input validation

## Requirements

- Linux / Kali Linux
- Bash
- OpenSSL
- Nano

## Usage

Make the script executable:

```bash
chmod +x toolkit.sh
```

Run it:

```bash
./toolkit.sh
```

Follow the interactive menu to select an operation.

## Purpose

This project was created as a practical introduction to **cryptography, Bash scripting, OpenSSL, and basic Linux file management**.

> **Note:** Use this toolkit only with files and systems you own or have permission to test.
